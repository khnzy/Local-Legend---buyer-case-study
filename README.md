# Local Legend - User Journey case study (buyer)
----
Objective: To map end to end buyer journey and identify pain points, suggest features to improve and define success metrics to track the changes.
- Conducted an end-to-end buyer journey analysis for a local commerce marketplace.
- Identified lack of trust and clarity during service discovery due to irrelevant listings and weak seller credibility signals.
- Proposed intent-based service discovery and seller trust indicators.
- Defined success metrics including search CTR, seller profile views, chat/call initiation, and add-to-cart to login conversion.
